1. Commit Source Code
  Primary Actor: Developer
  Description:
    - The developer commits source code changes to the version control system.
    - This action initiates the CI/CD workflow.

2. Trigger CI/CD Pipeline
  Primary Actor: Version Control System
  Description:
    - The version control system automatically triggers the CI/CD pipeline when new code is committed.

  Includes:
    - Build Application
    - Run Automated Tests
    - Deploy Application

3. Build Application
  Description:
    - The CI/CD system compiles the source code and resolves required dependencies to produce a build artifact.

4. Run Automated Tests
  Description:
    - The CI/CD system executes automated test cases to verify application correctness and stability.

5. Deploy Application
  Supporting Actor: Deployment Environment
  Description:
    - The CI/CD system deploys the application to the target environment after successful build and testing.

6. Detect Pipeline Failure
  Description:
    - The CI/CD system detects failures occurring during build, testing, or deployment stages.

  Includes:
    - Analyze Pipeline Logs
    - Classify Failure Type

7. Analyze Pipeline Logs
  Primary Actor: DevOps Engineer
  Description:
    - The CI/CD system collects and analyzes pipeline logs to identify error patterns and root causes.

8. Classify Failure Type
  Description:
    - The CI/CD system categorizes failures into predefined types such as build failure, test failure, or deployment failure.

9. Execute Recovery Action
  Supporting Actor: Deployment Environment, DevOps Engineer
  Description:
    - The CI/CD system executes predefined recovery actions such as retry, restart, or rollback based on the failure type.
  
  Extends:
    - Detect Pipeline Failure

10. Send Notifications
  Primary Actor: Notification Service, Developer, DevOps Engineer
  Description:
    - The CI/CD system sends notifications regarding pipeline success, failures, and recovery actions.
  
  Extends:
    - Trigger CI/CD Pipeline
    - Execute Recovery Action
