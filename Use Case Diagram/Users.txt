Actors of the System:

# Primary Actors
1. Developers:
    Committing the source code
    Receive build and test notifications
2. DevOps Engineer:
    Configure CI/CD Pipeline 
    Analyze pipeline logs
    Define deployment rules and recovery strategies

# Secondary Actors
3. Version Control System:
    Store source code
    Trigger CI/CD pipeline on commit or pull request
4. Deployment Environment:
    Host deployed applications
    Support Rollback and recovery actions
5. Notification Service:
    Send notification for pipeline success
    Send alerts for failures and recovery actions
