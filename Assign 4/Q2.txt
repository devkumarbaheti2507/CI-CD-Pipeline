Below are the application components of the system:
	1. CI/CD Pipeline controller:
		- Orchestrates entire pipeline
		- Manages execution flow
	2. Build Manager:
		- Compiles source code
		- Generates build artifacts
	3. Test Manager:
		- Executes automated tests
		- Produces test reports
	4. Deployment Manager:
		- Deploys application
		- Tracks deployment status
	5. Failure Detection Module:
		- Detects pipeline failures
	6. Log Analysis Module:
		- Analyzes logs
		- Extracts failure information
	7. Failure Classification Module:
		- Categorizes failure type
	8. Recovery Manager:
		- Executes retry or rollback
		- Restores system state
